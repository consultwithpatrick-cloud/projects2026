# projects2026

**Archived.** This repository is kept for its commit history only. Nothing here is
maintained.

It holds an early 2026 copy of **The Millionaire Engine**, a personal finance and
money-utilization tracker built as an installable progressive web app on a Google
Sheet backend. The current version lives in a separate private repository. The copy
here is a snapshot, and the demo build inside `millionaire-engine/engine-demo/`
carries sample data rather than real records.

The Apps Script backend in this snapshot ships with placeholder values for
`SPREADSHEET_ID` and `WEBHOOK_SECRET`. No live credential, endpoint, or personal
financial record is present in this repository.

See [millionaire-engine/README.md](millionaire-engine/README.md) for the
architecture and setup notes as they stood at the time.
